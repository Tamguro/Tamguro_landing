## 1. 한 문장 요약

> **기존 탐구로 팔레트와 Pretendard 한 가지 폰트만으로, Apple의 "한 화면 한 메시지" 구성과 Toss의 "스크롤로 이야기하는" 리듬을 빌려, 흰 바탕 위 쿨톤의 차분한 제품 페이지를 만든다.**

강조는 한 곳에만 씁니다. 브랜드 블루 `#319BFF`는 라벨·숫자·형광펜·진행 표시에만 쓰고, 넓은 면에는 쓰지 않습니다.

## 3. 디자인 레퍼런스: Apple · Toss에서 무엇을 가져왔나

레퍼런스는 https://www.apple.com/kr/ 과 https://toss.im/ 입니다. **레이아웃과 리듬만** 가져오고, 색과 폰트는 가져오지 않습니다(Apple의 SF Pro, `#0071E3`, Toss Product Sans는 쓰지 않음).

### Apple에서 가져온 것

| 패턴 | Apple 실측 | 탐구로 적용 |
|---|---|---|
| 얇은 블러 글로벌 내비 | 높이 44px, 12px 링크 | 높이 56px, 13px 링크, `bg-surface/80 backdrop-blur-xl` |
| 가운데 정렬 "한 화면 한 메시지" | 제목 56px/600 + 부제 28px/400 | 섹션 제목 56px/700 + 본문 19px |
| 짝을 이룬 알약 버튼 | 17px, radius 980px, 채움 + 테두리 | `PILL_PRIMARY`(잉크 채움) + `PILL_SECONDARY`(테두리) |
| 타일 그리드 | 12px 간격, 밝은·어두운 타일 교차 | A to Z 2×2, 시작하기 2열, 이용 안내 어두운 타일 |
| 회색 작은 글씨 푸터 | 12px, 회색 배경 | `bg-surface-muted`, 12px |

### Toss에서 가져온 것

| 패턴 | Toss 실측 | 탐구로 적용 |
|---|---|---|
| 화면을 채우는 큰 문장 | 80px/700, 자간 -0.02em | 문장 섹션 64px/700 (`Statement.tsx`) |
| 스크롤하면 커지는 둥근 카드 | 둥근 미디어 카드가 확대 | 히어로 하늘색 카드 `expand-on-view` |
| 글자가 스크롤에 따라 채워짐 | 단어가 회색 → 검정 | `ink-fill-on-view` |
| 고정된 폰 + 바뀌는 이야기 | 왼쪽 목록, 오른쪽 폰 고정 | 앱 화면 섹션 → 이후 **가로 슬라이드(고정 무대)** 로 발전 |
| 짧은 제목 + 16px 회색 본문 | 본문 `#727780` 계열 | 본문 `text-text-secondary` (`#667085`) |

## 4. 핵심 원칙 10가지

1. **팔레트와 폰트는 바꾸지 않는다.** 디자인 작업 전에 반드시 기존 토큰을 먼저 분석한다. 새 색은 앱·Figma에 이미 있는 색에서만 가져온다.
2. **한 화면에 한 메시지.** 섹션은 `작은 파란 라벨 → 큰 제목 → 회색 본문 → (버튼 또는 시각 요소)` 순서를 지킨다.
3. **강조는 한 곳에.** 브랜드 블루는 면이 아니라 점·선·글자에만 쓴다. 넓은 강조 면은 `wash`(아주 연한 파랑)나 잉크(어두운 타일)로 처리한다.
4. **전체 색감은 쿨톤.** 하늘색·흰색·연회색·잉크로 구성한다. 크림·베이지 같은 웜톤 면(`#FFFDF5`, `#E8E5DB`)은 쿨톤 배경 위에서 떠 보이므로 카드 면에 쓰지 않는다. (2026-10-05 피드백)
5. **굵기 대비로 성격을 만든다.** 폰트는 Pretendard 하나뿐이므로 900 ↔ 160 같은 극단적 굵기 대비(예: `A`**to**`Z`, "이해/실행/완성")로 개성을 낸다.
6. **구조 장치는 사실을 반영한다.** 01/02/03 번호는 실제 순서가 있는 곳(역할 슬라이드, 이용 단계 1·2·3)에만 쓴다. 순서가 없는 목록(A to Z 자료 4종)에는 번호 대신 태그(개념·매월 추가·실무·사례)를 쓴다.
7. **움직임은 의미가 있을 때만, 한 곳에 집중.** 대표 연출은 "앱 화면 가로 슬라이드" 하나다. 나머지는 등장 효과 정도로 조용하게 둔다.
8. **이미지는 선명해야 한다.** 폰 화면은 Figma 원본을 3배로 내보내고, 테두리(베젤)는 CSS로 그린다.
9. **어떤 폭에서도 겹치지 않는다.** 375 / 768 / 1024 / 1100 / 1280 / 1440px에서 글과 이미지가 겹치거나 가로 스크롤이 생기면 안 된다.
10. **품질 바닥선은 기본.** 키보드 포커스 표시, 동작 줄이기(reduced motion) 대응, 한글 단어 단위 줄바꿈은 매번 지킨다.

### 5.3 색 사용 규칙

- **면 비율**: 흰색(대부분) > 연회색·wash 타일 > 잉크 타일(페이지당 최대 2개: A to Z 개론 타일, 이용 안내) > 브랜드 블루(점·선·글자만).
- **브랜드 블루 위 흰 글씨 금지.** `#319BFF` 위 흰 글씨는 명암비 약 2.9:1로 AA(4.5:1)에 못 미칩니다. Apple·Toss처럼 파란 버튼을 만들고 싶어도 **주 버튼은 잉크 채움**을 씁니다. (예외: 11px 굵은 "NEW" 칩, 체크 원 안 ✓처럼 장식에 가까운 아주 작은 요소)
- **흰 글씨 + 브랜드 블루 글씨는 잉크 위에서만** 섞습니다(로고 마크의 `T`흰색 `G`파랑, 어두운 타일).
- **쿨톤 카드 공식**: `bg-surface` + `border border-border-cool` + (필요하면) `shadow-[0_18px_30px_-20px_var(--shadow-phone)]`.
- **그림자는 한 가지 색만**: `--shadow-phone`(`#0D0F17` 18%). 퍼짐은 크게, 진하기는 약하게.

## 6. 타이포그래피

### 6.1 폰트

- **Pretendard Variable 하나만** 씁니다(`next/font/local`, 굵기 45–920, `display: swap`).
- 클래스는 `font-sans`(기본 상속). 새 코드에 `font-['Pretendard']`를 쓰지 않습니다(대체 폰트가 없어 로컬 미설치 환경에서 깨질 수 있음).
- 숫자(01/02/03, byte, 진행 번호)는 `tabular-nums`.

### 6.2 굵기 사용

| 굵기 | 용도 |
|---|---|
| 900 | `A`·`Z` (A to Z 타일) |

### 6.4 형광펜 (Highlighter)

- 페이지 전체에서 쓰는 단 하나의 장식입니다. `.highlighter`: `--highlight`(브랜드 블루 28%)를 글자 아래 42% 높이, 88% 위치에 깔고, 줄바꿈 시 `box-decoration-break: clone`.
- 사용처: 히어로 "**진짜**"(로드 시 0.65초 뒤 왼쪽→오른쪽으로 칠해짐 `.highlighter-sweep`), 시작하기 "**진짜 가치**".
- 같은 의미("진짜 가치")에만 씁니다. 아무 단어에나 칠하지 않습니다.

## 7. 한글 조판 규칙

1. `body`에 `word-break: keep-all; overflow-wrap: break-word;` — **단어 중간에서 줄이 바뀌지 않게** 합니다. (예전 버그: "시작하세/요", "있습니/다")
2. 그래도 어색하게 한 단어만 남는 경우(고아 단어)는 **직접 줄을 바꿉니다.**
   - 예: 교세특 워크북 설명 `"워크북을 따라가면 교세특이 뚝딱,\n매월 추가되는 워크북"` — 모바일에서 "매월"이 윗줄 끝에 홀로 남던 문제를 해결(2026-10-05 피드백).
   - `TileHeading`의 설명 문단은 `whitespace-pre-line`이므로 문자열에 `\n`을 넣으면 됩니다.
3. 쉼표·조사 앞에서 끊지 않습니다. 끊는 위치는 의미 단위(쉼표 뒤, 구 사이)입니다.
4. 데스크톱 전용 줄바꿈은 `<br className="hidden sm:block" />`처럼 표시 폭을 지정합니다.
5. 마침표에 브랜드 블루를 쓰는 것은 히어로 "실현하다**.**" 한 곳뿐입니다.

## 11. 모션

### 11.1 원칙

- **대표 연출은 하나(앱 화면 가로 슬라이드).** 나머지는 짧은 등장 효과.
- 스크롤 연동 효과는 CSS **scroll-driven animation**(`animation-timeline: view()`)으로 만들고 `@supports`로 감쌉니다. 지원하지 않는 브라우저(예: Firefox)에서는 **완성된 상태**로 보입니다.
- 모든 장식 모션은 `@media (prefers-reduced-motion: no-preference)` 안에 둡니다.

### 11.2 효과 목록

| 클래스 | 동작 | 값 |
|---|---|---|
| `.rise` | 로드 시 18px 아래에서 떠오름 | 700ms `cubic-bezier(0.2, 0.7, 0.2, 1)`, 요소별 `animationDelay` |
| `.highlighter-sweep` | 형광펜이 0% → 100% 칠해짐 | 700ms `cubic-bezier(0.6, 0, 0.2, 1)`, 650ms 지연 |
| `.reveal` | 스크롤로 등장 | `entry 0% → entry 45%` |
| `.expand-on-view` | 카드가 94% → 100% | `entry 0% → cover 35%` |
| `.ink-fill-on-view` | 글자가 회색 → 잉크 | `entry 60% → cover 55%` |
| `.draw-on-view` | 선이 왼쪽 → 오른쪽 | `entry 20% → cover 45%` |

주의: 한 요소에 `rise`와 스크롤 효과를 같이 걸지 않습니다(`animation` 속성이 서로 덮어씀).

### 11.3 앱 화면 가로 슬라이드 (`.app-rail-*`)

**구조**
- 섹션 높이 `340vh`(데스크톱) → 안쪽 무대가 `sticky top-[56px] h-[calc(100vh-56px)]`로 고정.
- 트랙 폭 300%, 패널 3개(각 1/3).

**계산 (JS, `requestAnimationFrame`)**
- 진행도 `raw = 0 → 2` (= 스크롤 위치 / 고정 구간 길이 × 2).
- **멈춤 구간(HOLD = 0.2)**: 각 단계 구간의 앞 20%·뒤 20%는 움직이지 않고, 가운데 60%에서만 `smoothstep`으로 이동 → 각 역할 화면에 "착지"하는 느낌.
- JS는 CSS 변수만 씁니다: 섹션 `--e`(0→2), 패널마다 `--d`(현재 단계와의 부호 있는 거리, -1~1)와 `--ad`(절댓값).

**CSS 변형 (데스크톱)**

| 대상 | 변형 |
|---|---|
| 트랙 | `translate3d(calc(var(--e) * -100% / 3), 0, 0)` |
| 큰 번호 | `translateX(--d × -180px)` → 패널보다 빨리 움직이는 패럴랙스 |
| 글 블록 | `opacity: 1 - |d| × 0.85` |
| 할로 | `scale(1 - |d| × 0.4)` |
| 폰 | `translateX(--d × -120px) rotateY(--d × 24deg) scale(1 - |d| × 0.14)`, 원근 1400px |
| 진행 바 | `scaleX(clamp(0, --e - i + 1, 1))` → 연속 채움 |

**자동 맞춤(snap)**
- 스크롤이 200ms 멈추면 가장 가까운 단계로 부드럽게 이동.
- 맞춤이 진행되는 동안에는 다시 맞추지 않음(이전 버그: 맞춤이 맞춤을 불러 위아래로 흔들림).
- 휠·터치·키보드 입력이 들어오면 즉시 맞춤 취소.

**주의**
- 모바일 전용 규칙(`.app-rail-fill[data-active]`)은 반드시 `@media (max-width: 1023.98px)` 안에. 밖에 두면 데스크톱에서 진행 바가 50%를 넘는 순간 100%로 튐(이전 버그).
- 동작 줄이기: 번호·폰·할로 변형 제거(가로 이동은 유지).

## 15. 카피(문구) 원칙

- **사용자 쪽 말로.** 기능 이름이 아니라 학생·학부모가 아는 말로(세특, 교세특, 학종, 생기부).
- **짧은 제목 + 한 줄 설명.** 제목은 두 줄 이내, 설명은 두 줄 이내.
- **버튼은 결과를 말한다.** "자료 구독하기", "멘토 찾아보기", "학종 A to Z 둘러보기". 같은 동작은 어디서나 같은 이름.
- **꾸며낸 후기·인용 금지.** 합격자 발언처럼 보이는 가짜 인용을 만들지 않습니다. 예시 그림 속 문구는 실제 상품 설명에서 가져옵니다(예: "따라가면 완성되는 교세특"은 "워크북을 따라가면 교세특이 뚝딱"에서).
- **법적 고지 유지**: 초중고등교육법 준수 문구.
- 문구를 직접 바꾼 경우(체크리스트, 고지 문구 등)는 그 문구가 최신 기준입니다.

## 18. 하지 말 것 (Anti-patterns)

- 새 폰트 추가, `font-['Pretendard']` 같은 대체 없는 폰트 지정.
- 컴포넌트에 hex 직접 사용, 앱·Figma에 없는 새 색 발명.
- 크림·베이지 같은 웜톤 면을 카드에 사용.
- 브랜드 블루 면 위 흰 글씨(버튼 포함).
- 순서 없는 목록에 01/02/03 번호.
- 고정 픽셀 absolute 레이아웃, 고정 높이 카드 안에 큰 이미지.
- 할로·배경에 블러.
- 한 요소에 여러 `animation` 클래스 중첩.
- 데스크톱 스크롤 연동 값을 덮어쓰는 모바일 규칙을 미디어 쿼리 밖에 두기.
- 흐릿한 이미지(1배 캡처, 베젤까지 구운 이미지 확대).
- 가짜 후기·가짜 인용.
- 템플릿처럼 보이는 장식(의미 없는 그라데이션, 큰 숫자 + 작은 라벨 + 그라데이션 조합 등).

## 20. 변경 전 체크리스트
